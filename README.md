# جواب تمرین های دوره پایتون مقدماتی جادی در مکتب خونه

این کدها رو بیشتر برای دوره کردن پایتون و مجبور کردن خودم به فعالیت در گیت هاب گداشتم و امیدوارم کمکتون کنه، اگر مفید بود ممنون میشم استار بدید🌟

برای صلاح یادگیری خودتون پیشنهاد میدم فقط وقتی خیلی کارتون گیره به این کدها رجوع کنید. تازه بیشتر فان برنامه نویسی هم دقیقا همون لحظه ایه که خودت باگو پیدا میکنی یا به راه حل میرسی!
